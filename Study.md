# Equação Polinomial

## Grau

O grau é definido pelo maior expoente da equação, x^0 será constante, x^1 é linear e x^2 é quadrática.

## Forma reduzida

A forma reduzida é aquela na qual os valores a direita do sinal de igualdade são substituídos por 0.
Por exemplo:

```
x^2 + 3x + 42 = 7x + 7
x^2 + 3x - 7x + 42 - 7 = 0
x^2 - 4x + 35 = 0
```

## Fórmulas

Para quadráticas, só aplicar Bhaskara:

```
ax^2 + bx + c = 0
(-b (+-) raiz_quadrada(delta)) / (2 * a)

delta = b^2 - 4 * a * c

Se o valor de delta for:
Positivo, X vai ter duas distâncias, a primeira onde -b é somado com a raiz e outra onde -b é subtraído pela raiz.
Zero, X só tem um valor já que o 0 não afeta o valor de -b
Negativo, irreal, já que não existe raiz de um número negativo dentro dos números reais.
```

Para lineares só aplicar o descobrimento de x:

```
ax + c = 0
ax = -c
x = -c / a
```

Para constantes só checar se a condição é verdadeira

```
c = c
c - c = 0
```
